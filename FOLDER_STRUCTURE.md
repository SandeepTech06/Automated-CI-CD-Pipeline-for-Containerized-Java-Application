# Complete Folder Structure

```text
project-root/
├── .github/
│   └── workflows/
│       └── main.yml
├── src/
│   ├── main/
│   │   └── java/
│   │       └── com/
│   │           └── example/
│   │               └── cicd/
│   │               └── App.java
│   └── test/
│       └── java/
│           └── com/
│               └── example/
│                   └── cicd/
│                   └── AppTest.java
├── target/
├── Dockerfile
├── pom.xml
├── README.md
├── PROJECT_REPORT.md
├── SYNOPSIS.md
├── VIVA_QUESTIONS.md
├── GIT_COMMANDS.md
└── FOLDER_STRUCTURE.md
```

## Folder Purpose

- `.github/workflows/`: Stores GitHub Actions workflow files.
- `src/main/java/`: Contains the application source code.
- `src/test/java/`: Contains test classes.
- `target/`: Contains Maven build outputs such as the executable JAR.
- `Dockerfile`: Defines the container image build instructions.
- `pom.xml`: Maven project configuration.
- `README.md`: Main project documentation.
- `PROJECT_REPORT.md`: Academic report for submission.
- `SYNOPSIS.md`: Short synopsis for university submission.
- `VIVA_QUESTIONS.md`: Viva preparation questions and answers.
- `GIT_COMMANDS.md`: Common Git and GitHub commands.

## Package Names

The Java classes currently use the `com.example.cicd` package structure in the application source and tests. If you rename the package later, keep the source and test folders aligned with the new package name.

## Notes

The `target/` folder is generated by Maven and should not be committed to version control.
